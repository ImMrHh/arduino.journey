Move the sensor slider, adjust the threshold, and watch the LED and “Serial Monitor” respond. / Mueve el sensor, ajusta el umbral y observa el LED y el “Monitor Serie”.

Sensor input / Entrada del sensor

raw: 320 voltage: 1.56 V

mapped: 79 map() idea: map(x,0,1023,0,N)

Threshold + LED / Umbral + LED

LED: OFF / APAGADO

Serial Monitor / Monitor Serie

baud: 9600 delay: 200 ms

Connect to Arduino / Conectar con Arduino

  • Sensor: VCC → 5V, GND → GND, signal → A0
  • Serial: Tools → Serial Monitor → 9600 baud
  • Code core: analogRead(A0), map(), if() threshold, digitalWrite(LED)

Idea de código / Code idea:

// Read sensor
int sensorValue = analogRead(A0);

// Map to 0–255
int mappedValue = map(sensorValue, 0, 1023, 0, 255);

// Threshold LED
if (sensorValue > 500) { digitalWrite(9, HIGH); } else { digitalWrite(9, LOW); }

// Print to Serial
Serial.print("raw="); Serial.print(sensorValue);
Serial.print(" mapped="); Serial.println(mappedValue);
