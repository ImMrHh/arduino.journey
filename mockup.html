02

Blink — Your First External LED

Connect an LED and resistor to a breadboard and control it with digital output.

Digital Output Breadboard Resistors 40 min
Learning Objectives
  • Wire an LED and resistor correctly on a breadboard
  • Understand why resistors protect LEDs from burning out
  • Control an external LED using digitalWrite()
Materials

What You Need

  • Arduino Uno
  • Breadboard
  • 1× LED (any colour)
  • 1× 220 Ω resistor
  • 2× jumper wires
  • USB cable
Background

Why Does an LED Need a Resistor?

An LED (Light Emitting Diode) only allows current to flow in one direction. If you wire it backwards, it simply won't light up — that's fine, just flip it. But if you connect an LED directly to a pin without a resistor, too much current flows through it and it burns out in seconds.

A resistor limits the current to a safe level. For a standard red or green LED connected to a 5 V pin, a 220 Ω resistor keeps the current around 15–20 mA, which is exactly the safe operating range.

A breadboard lets you build circuits without soldering. The five holes in each row of the middle section are all connected together internally. The long rails on the sides (marked + and −) run the full length of the board.

Wiring

Build the Circuit

Wiring diagram — /images/lesson02-wiring.png
  1. Insert the LED into the breadboard. Long leg (anode +) in one row, short leg (cathode −) in the next row.
  2. Connect one leg of the 220 Ω resistor to the same row as the long leg.
  3. Connect the other leg of the resistor to pin 9 on the Arduino with a jumper wire.
  4. Connect the short leg of the LED to a GND pin on the Arduino with a jumper wire.
Code

Upload This Sketch

lesson-02-blink.ino Arduino C++ 
// External LED Blink
// LED connected to pin 9 through a 220 Ω resistor

const int LED_PIN = 9;  // Give the pin a readable name

void setup() {
  pinMode(LED_PIN, OUTPUT);  // Set pin 9 as output
}

void loop() {
  digitalWrite(LED_PIN, HIGH);  // LED on
  delay(500);                    // Wait 0.5 seconds
  digitalWrite(LED_PIN, LOW);   // LED off
  delay(500);                    // Wait 0.5 seconds
}
Understanding the Code

What Each Line Does

  • const int LED_PIN = 9 — stores the pin number as a named constant. Using a name instead of a bare number makes the code easier to read and change later.
  • pinMode(LED_PIN, OUTPUT) — tells the Arduino that pin 9 will send signals out, not read them in.
  • digitalWrite(LED_PIN, HIGH) — sends 5 V to pin 9, pushing current through the resistor and the LED, lighting it up.
  • delay(500) — pauses the program for 500 ms (half a second). Nothing else happens during a delay.
  • digitalWrite(LED_PIN, LOW) — sets pin 9 to 0 V, stopping current flow and turning the LED off.
Challenge
Try This

Can you make the LED blink a pattern — three short blinks followed by one long one? Add more digitalWrite and delay lines to your loop() to create your own sequence.

Reflection

Discuss With Your Group

  1. Why does an LED need a resistor in series with it?
  2. What is the difference between the long leg and the short leg of an LED?
  3. If you wanted the LED to blink exactly three times per second, what delay value would you use?
Troubleshooting

If Something Doesn't Work

Problem Likely Cause Fix
LED does not light up LED wired backwards Flip the LED in the breadboard
LED lights but does not blink Code not uploaded Click Upload in the IDE
Upload error Wrong port selected Go to Tools > Port and select the correct one
LED very dim Resistor value too high Check resistor bands — use 220 Ω (red-red-brown)
