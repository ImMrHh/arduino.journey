Pacing Guide

10-lesson schedule for 40-minute sessions, groups of 3 students.

Format

Schedule Overview

1 lesson every 2 weeks · 40-minute sessions · groups of 3 students.

LESSON 01 What is Arduino?
Session time40 minutes
Prep time15 minutes
ObjectivesStudents identify board parts, install IDE 2, upload Blink
MaterialsArduino Uno + USB cable per group, computers with IDE 2 pre-installed if possible
ChallengesIDE installation takes time on student computers — pre-install if possible. Some USB cables are charge-only
NotesOrientation lesson. Focus on getting everyone to a successful first upload. Don't go deeper than Blink
LESSON 02 Blink (External LED)
Session time40 minutes
Prep time10 minutes
ObjectivesStudents wire an LED with resistor on breadboard, control it from code
MaterialsBreadboard, 1× LED, 1× 220 ohm resistor, 2× jumper wires per group
ChallengesLED polarity errors are very common — have spare LEDs ready
NotesSpend 5 minutes demonstrating the breadboard layout before groups start wiring
LESSON 03 Multiple LEDs
Session time40 minutes
Prep time10 minutes
ObjectivesStudents wire 3 LEDs, use arrays and for loops
Materials3× LEDs, 3× 220 ohm resistors, 6+ jumper wires per group
ChallengesFor loop indexing confuses students at first. Array concept may need extra time
NotesDraw the for loop execution order on the board — walk through i=0, i=1, i=2 step by step
LESSON 04 Button Input
Session time40 minutes
Prep time10 minutes
ObjectivesStudents wire a button, read digital input, understand pull-up resistors
Materials1× push button, 1× LED + resistor per group
ChallengesStudents often forget INPUT_PULLUP and get floating pin readings. Active LOW logic confuses many
NotesDemonstrate floating pin behavior first (without INPUT_PULLUP) so students understand why pull-up is needed
LESSON 05 Buzzer and Sound
Session time40 minutes
Prep time10 minutes
ObjectivesStudents wire a passive buzzer, use tone() to play a melody
Materials1× passive buzzer per group — verify they are passive, not active
ChallengesActive buzzers only produce one tone — have students verify buzzer type
NotesKeep volume expectations realistic — the small buzzers are quiet. Students often expect louder sound
LESSON 06 Analog Input
Session time40 minutes
Prep time10 minutes
ObjectivesStudents wire a potentiometer, use analogRead() and map(), control LED brightness
Materials1× potentiometer (10k), 1× LED + resistor per group
ChallengesPotentiometer leg identification. Students sometimes confuse analog and PWM pins
NotesOpen Serial Monitor early — seeing the numbers change as they turn the pot is very engaging and confirms the circuit is working
LESSON 07 Sensors
Session time40 minutes
Prep time20 minutes (library install)
ObjectivesStudents read LDR and DHT11 sensor data, display it in Serial Monitor
Materials1× LDR + 10k resistor, 1× DHT11 module per group. Pre-install DHT library if possible
ChallengesDHT library installation. Students sometimes open the wrong library (there are several DHT libraries)
NotesInstall DHT sensor library by Adafruit specifically. Walk through Library Manager as a class before groups start
LESSON 08 Mini Challenge
Session time40 minutes
Prep time5 minutes
ObjectivesStudents design and build either a reaction timer or traffic light independently
MaterialsFull component kit available per group
ChallengesGroups that haven't fully understood previous lessons will struggle — be ready with more scaffolding
NotesAssessment-friendly — observe each group's process. Ask probing questions while they build
LESSON 09 DFPlayer Mini Setup
Session time40 minutes
Prep time30 minutes (SD card prep, library install)
ObjectivesStudents wire DFPlayer Mini, load SD card, play first audio file
MaterialsDFPlayer Mini, microSD card (FAT32, mp3/ folder with numbered files), small speaker, 1k resistor, DFRobotDFPlayerMini library installed
ChallengesSD card format issues are the most common problem — pre-format and load cards before class
NotesPre-load the SD cards with a few short MP3 files. FAT32 formatting + correct folder/filename structure is the biggest hurdle
LESSON 10 MP3 Player Final Build CAPSTONE
Session time40 minutes
Prep time10 minutes
ObjectivesStudents build a complete MP3 player with 5-button control and status LED
MaterialsFull kit from Lesson 09 plus 5 push buttons
ChallengesWiring complexity with 5 buttons. Debounce logic takes time to understand
NotesCelebrate completion — allow 5 minutes at the end for groups to demo their player
