Classroom Setup

IDE installation, library setup, hardware kit, SD card prep, and common problems.

Software

Arduino IDE 2 Installation

  1. Go to arduino.cc/en/software and download Arduino IDE 2 for your operating system.

  2. Install with default settings.

  3. Connect an Arduino Uno and verify it appears under Tools > Port.

Windows: Some boards require the CH340 driver if the port is not detected. Download from the chip manufacturer's site.
iPad / Chromebook: Use the Arduino Web Editor at create.arduino.cc — students need a free Arduino account.

Lessons 09–10

SD Card Preparation

  1. Format the microSD card as FAT32.

  2. Create a folder named exactly mp3 at the root of the card.

  3. Add MP3 audio files named 0001.mp3, 0002.mp3, etc.

  4. Keep files short — 30–60 seconds each — to keep class focused.

Pre-format and load all SD cards before class — this is the most common source of errors in Lessons 09 and 10.
Layout

Classroom Layout Suggestions

→Arrange tables in groups of 3 or islands — students share one Arduino per group
→Ensure each station has enough USB ports or a power bar — one Arduino per group
→Keep a spare kit with extra LEDs, resistors, and a working Arduino at the front — components break
→Display the lesson page on a projector or shared screen during build steps
Troubleshooting

Common First-Day Problems

ProblemSolution
IDE not detecting the board Check USB cable (data vs charge-only); install CH340 driver on Windows
Students modifying the wrong sketch Have students always start from File > New
LED not lighting up 90% of cases are reversed polarity — flip the LED
Upload error: port busy Close Serial Monitor before uploading
Groups finishing very quickly Direct them to the Challenge section of each lesson
Groups not finishing in 40 min Pre-wire the circuit for the last 10 minutes if needed
