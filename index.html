Capstone Project

Build a Working MP3 Player

The course builds toward a fully functional MP3 player using an Arduino Uno and DFPlayer Mini module. Students wire the circuit, load audio files onto an SD card, and write code to control playback with physical buttons. Every concept from Lessons 1–8 feeds directly into this final build.
