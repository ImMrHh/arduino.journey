# Week 3: Potentiometer & PWM

Welcome to Week 3! This week, we explore how potentiometers control LED brightness using Pulse Width Modulation (PWM).

## Lesson Overview

- Understand what a potentiometer is and how it works as a variable resistor.
- Learn about PWM and how it simulates analog output with digital signals.
- See how to read analog input from a potentiometer and control LED brightness.
- Hands-on coding and wiring practice.
